# notes-and-cadences

Notes and Cadences contains WAV files with - as the name implies - notes and cadences.
These high quality sounds were played on a (virtual?) grand piano.

## Usage

These audio files can be used for any purpose. 

However, they are intended to be used for contextual ear training. i.e. recognize tones in the context of a key. 

This is a relative pith exercise that goes as follows:

1. A cadence is played to establish the key (this can be a major or minor key)
1. Then a random note is played
1. Then the student tries to recognize how this note sounds within the context of that key, and answers with the scale degree (or note name if the key is known)

The first software program that offered this type of ear training was Functional Ear Trainer (by Alain Benbassat) in 2002.
